Print_Task串口DMA高性能传输修改说明
======================================

修改日期: 2026/1/28
修改内容: 将Print_Task的串口传输改为高性能DMA模式

一、修改的文件
------------
1. main/board_config.h
   - 启用Print串口DMA功能: boardPRINT_IFACE_DMA_EN = 1

2. Hardware/Print/print_iface.c
   - 使用ESP32标准UART API实现DMA传输
   - 增大缓冲区大小
   - 移除UHCI驱动依赖

二、主要改进点
------------

1. DMA发送优化
   - ESP32的uart_write_bytes()内部已使用DMA硬件
   - 数据复制到TX FIFO后立即返回
   - DMA硬件自动完成后续传输
   - 无需手动管理DMA状态

2. DMA接收优化
   - ESP32 UART驱动内部已使用DMA
   - 增大RX和TX缓冲区到2048字节
   - 使用UART事件队列处理接收数据
   - 数据直接写入环形缓冲区

3. 缓冲区优化
   - DMA缓冲区大小: 256 -> 2048字节
   - TX缓冲区大小: 256 -> 2048字节
   - 提高数据吞吐量和抗抖动能力

三、ESP32 UART DMA工作原理
-------------------------
ESP32的UART驱动内部已使用DMA硬件进行数据传输：
- TX: uart_write_bytes() 将数据复制到TX FIFO，由DMA硬件异步发送
- RX: UART中断触发时，DMA将数据从RX FIFO搬运到内存缓冲区
- 通过事件队列通知应用程序有数据到达

**关键点**：
- uart_write_bytes() 是阻塞调用，但内部使用DMA硬件加速
- 数据写入FIFO后快速返回（相比传统轮询方式更快）
- 适合ESP32C61等高性能芯片

四、性能提升
------------
1. 发送性能
   - ESP32内部DMA硬件加速发送
   - 大缓冲区支持高频数据传输
   - 相比纯软件轮询方式速度更快

2. 接收性能
   - ESP32内部DMA硬件处理接收
   - 大缓冲区避免数据溢出
   - 事件驱动机制，实时性高

3. 系统性能
   - DMA硬件处理数据传输，释放CPU资源
   - 提高系统整体响应速度
   - 支持更高波特率传输（最高5Mbps）

五、使用说明
------------
1. DMA功能已自动启用（boardPRINT_IFACE_DMA_EN = 1）
2. 发送数据时，uart_write_bytes()自动使用DMA硬件
3. 接收数据由UART驱动自动处理，通过事件队列通知
4. 如需关闭DMA，可设置 boardPRINT_IFACE_DMA_EN = 0

六、注意事项
------------
1. ESP32的uart_write_bytes()是阻塞调用，但内部使用DMA加速
2. 大缓冲区（2048字节）提供更好的性能
3. UART驱动内部已使用DMA，无需额外配置
4. 485模式下，需要在发送完成后手动切换回接收模式

七、兼容性
----------
1. 保持原有接口不变，上层应用无需修改
2. 支持DMA和非DMA模式切换
3. 向后兼容原有代码逻辑
4. 使用ESP32标准UART API，无第三方依赖

八、技术细节
------------
1. DMA发送：
   - uart_write_bytes() 将数据复制到TX FIFO
   - DMA硬件从FIFO读取数据并异步发送
   - 发送速度远快于纯软件轮询

2. 发送完成检测：
   - uart_get_buffered_data_len() 获取TX FIFO剩余数据
   - 返回0表示FIFO为空，DMA传输完成
   - 可用于485模式切换

3. 接收处理：
   - UART中断触发DMA搬运数据
   - 事件队列通知应用层有数据到达
   - uart_read_bytes() 从内存缓冲区读取数据
   - 数据写入环形缓冲区供协议层处理
