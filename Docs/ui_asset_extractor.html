通用 UI 素材提取器

把已确认的 UI 设计稿（HTML）拖进来即可 —— 自动扫描其中所有内联 SVG 图标，读取设计稿里真实生效的配色与变换， 并由浏览器按时间轴驱动 CSS 动画抽取序列帧。设计稿即唯一事实来源，无需在本工具里二次实现任何路径。

1. 投放设计稿
支持同时加载多个设计稿，分别提取；导出时多设计稿会自动按设计稿分子目录
📥 点击选择，或把设计稿 .html / .htm 拖到这里
纯本地浏览器端解析，不上传网络 · 设计稿需为自包含 HTML（内联 SVG + 内联 CSS）
外链图片 / 外链 CSS 不会被加载；<svg> 以外的 div 绘制的装饰条不在提取范围内
本地文件请用上方【选择文件】或把源码粘贴到下面 —— 两者在 file:// 下都能用； 此输入框只用于 http(s):// 远程地址（file:// 打开时浏览器会拦截任何按路径读取的请求）。
